# 踩坑记录（anti-patterns）

> 这是整个库里 ROI 最高的文件。每次被 agent 坑过、自己踩过、线上挂过，立刻追加一条。
> **新任务开始前，agent 必须扫一眼最新 10 条。**

## 记录模板

```
## [YYYY-MM-DD] 短标题
- **场景**：在什么项目、什么任务下
- **症状**：agent 做了什么 / 出了什么问题
- **根因**：为什么会这样
- **规避**：以后怎么避免（具体到"遇到 X 情况要做 Y"）
- **标签**：#java #spring #vibecoding 等
```

### 示例：[2026-09-12] 不要让 agent 自己决定测试要不要跑
- **场景**：某次修一个 Python bug
- **症状**：agent 改完说"逻辑很简单应该没问题"，没跑测试就交付，结果导入路径写错
- **根因**：agent 倾向于不跑命令，因为跑命令有失败风险、要多说话
- **规避**：在任务里直接说"改完跑 `pytest tests/xxx -x`"，不要问"要不要跑测试"
- **标签**：#vibecoding #workflow
